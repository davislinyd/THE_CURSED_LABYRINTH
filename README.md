# 幽燈魔境 THE CURSED LABYRINTH

原創日式黑暗動作 RPG，瀏覽器直接遊玩。本分支 `ps2-remake` 把原本的 FC 版（標籤 `fc-v1`）重製成 PS2 世代的畫面與音樂：

- **2D 模式**（大地圖、村莊、章節古道）：斜角視角的砍殺動作，可用滑鼠點擊移動與攻擊。
- **3D 模式**（迷宮、Boss）：第三人稱自由移動的即時劍戟動作，有連擊、強攻擊、防禦、看準時機的反擊、閃避與鎖定；**迷你地圖可隨時開關**。

目前完成**第一章**完整試玩：序幕 → 灰谷平原 → 灰谷村 → 朽木古道 → 朽木洞窟 → 朽根老樹 → 封印 I 青銅鏡。

角色、故事、介面、樂曲皆為原創；第三方素材只用 CC0 與 OFL 授權，清單見 [CREDITS.md](CREDITS.md)。

## 執行

```sh
npm install
npm run dev        # 開發伺服器
npm run build      # 型別檢查 + 產出 dist/
npm run preview    # 預覽 dist/
npm test           # Vitest
```

`public/assets/`（貼圖、模型、樂器取樣、音效）由素材管線產生，執行遊戲前必須存在：

```sh
npm run assets     # 下載 scripts/assets/sources.mjs 列出的素材到 assets-src/，再轉檔輸出到 public/assets/
```

需要 PATH 上有 `ffmpeg`、`cwebp`、`unzip`。同時會產生 `public/assets/manifest.json`、`public/licenses/` 與 `CREDITS.md`。

選單、暫停、設定、對話框與商店都能用滑鼠：**左鍵**確定、**右鍵**取消；滑鼠指到哪一列，游標就跟到哪一列。3D 模式遊戲中會鎖定游標，第一下點擊只負責鎖定（瀏覽器規定），不會出招。2D 與 3D 的大地圖、村莊、古道、迷宮都有迷你地圖，戰爭迷霧隨探索揭開並存檔；大地圖、村莊、古道未探索的地面在畫面上也蓋著流動的墨霧，主角靠近時散開。

畫面內的按鍵提示會依目前使用的裝置（鍵盤或手把）自動切換。標題與暫停選單都有「操作說明」頁。

## 遊戲系統

- **難度**：開新遊戲時選簡單／一般／困難，之後可在暫停選單的「設定」中更改，隨存檔保存。簡單：受到的傷害減半、敵人血量 ×0.7、不易疲勞；困難：受到的傷害 ×1.5、敵人血量 ×1.3、容易疲勞。
- **跑步與疲勞**：C 鍵切換跑步（走路的 1.5 倍速）。連續跑約 8 秒、或走路約 2 分鐘會力竭（HUD 體力條下方的細條）；力竭時不能跑、只能以約 6 成速度走，停下約 3 秒後恢復，停下約 5 秒完全消除疲勞。攻擊與閃避不受影響。
- **劍的等級**：擊敗敵人釋放紅色魂火，靠近即自動吸收，累積後升級提高攻擊力；黃色魂火回復體力。
- **掉落物**：2D 模式的敵人與破甕會掉落金錢、藥草、符咒，地上顯示名稱，走過即撿起。
- **道具**：藥草（回復 6）、靈藥（全回復）、符咒（投擲，貫穿靈體）。
- **村莊**：交談、商店、旅店（回復並存檔）。
- **迷宮**：門、鑰匙門、可破木板、幻牆（持青銅鏡會閃爍）、黑暗區（需幽靈燭）、寶箱、石碑、地圖與磁石。
- **存檔**：旅店、神社、進出迷宮與大地圖時自動存檔，存在瀏覽器 LocalStorage（`yuto-makyo.save.v2`）。FC 版存檔（`.v1`）不相容，標題畫面會提示。
- **接關**：死亡後可接關 3 次（體力全滿、金錢減半、回到最後存檔點），用完為 GAME OVER。
- **設定**：語言（English／繁體中文）、BGM／SFX 音量、渲染解析度（自動／100%／75%／50%）、特效品質（高／低）、CRT 效果、迷你地圖；遊戲中另有難度。

## 技術

- **渲染**：Three.js 0.187（WebGL2）。畫面填滿視窗（邏輯高度 448，寬度 640～1045，支援到 21:9），內部解析度依視窗與 DPR 而定，自動模式會依幀率調整。後製依序是墨線與墨暈（`InkPass`，由深度貼圖產生）、Bloom、ACES 色調映射、SMAA，最後是「褪色木版畫」收尾：靛藍暗部與赭黃亮部、保留朱紅的低彩度、色階化、和紙纖維、套色錯位、焦邊，以及可選的斑點刮痕與 CRT。特效品質為「低」時保留墨線與和紙，關閉 Bloom、墨暈、套色錯位與斑點。介面是疊在上方的 2D canvas，面板為染舊的和紙與毛筆邊框。
- **3D 迷宮**：由迷宮格子資料生成起伏的岩壁、地面與天井；圓形對矩形碰撞；固定數量的點光源池分配給附近燈籠，避免著色器重編譯。追隨鏡頭在牆邊會拉近或升高。
- **斜角模式**：正交鏡頭；地面以遮罩貼圖混合草地與道路；山崖、杉林（Instancing）、水面、橋、墓地、彼岸花、房屋皆由格子資料生成；月光陰影跟隨主角；擋在主角前方的樹、山崖、屋頂會以抖動方式透明化。點擊移動使用 A* 尋路。
- **角色**：武士、敵人與 Boss 都是程式組裝的剛體部件骨架，動畫為關鍵影格片段；揮刀時機由純邏輯狀態機控制（60 Hz），並有測試確認動畫長度與判定時間一致。
- **原創 3D 道具**：卒塔婆、地藏、倒塌的鳥居、斷柵欄、插在地上的刀槍與箭、破旗、洞窟的腐朽木支架，都用 Blender 腳本（`scripts/blender/props.py`，需 Blender 5.x）建模，風化痕跡畫在頂點色上，匯出到 `scripts/blender/export/`（有進版控），再由 `npm run assets` 最佳化。只有修改模型時才需要開 Blender。
- **音樂**：取樣器引擎（多取樣音色、ADSR、延音循環、殘響送出、主壓縮器），以擴充後的 MML 原創作曲，樂器取樣來自 VSCO 2 CE 與 VCSL（CC0）：弦樂、銅管、長笛（以滑音與顫音模仿尺八）、豎琴、定音鼓；琴的聲部以越南古箏（Đàn tranh）取樣演奏，太鼓用大型民族鼓取樣。
- **字型**：Cinzel 與 Noto Serif TC（OFL），只擷取用到的字。新增中文字串後需重新擷取（開發用，需 `pip install fonttools brotli`）：

  ```sh
  python3 scripts/subset_fonts.py assets-src/fonts
  ```

## 測試

`npm test` 涵蓋：迷宮可解性（鑰匙、拉桿狀態窮舉）、大地圖各封印的可達範圍、斜角地圖（尺寸、起點到終點與每個敵人／甕／村民的連通、3×3 轉換、A* 不切角）、迷宮格子幾何與碰撞、主角狀態機與敵人行為、動畫片段長度、走路循環的平順（關節不在姿勢點急停或彈回）、動作交叉淡入被打斷時不跳動、樂曲小節長度、素材清單（每個檔案存在且有授權資訊）、翻譯與字型涵蓋、密技輸入、戰爭迷霧、疲勞與難度、追背鏡頭（按倒退鍵時不再來回翻轉）、視線與通行判定的連續性。

## 測試用密技

遊戲中依序輸入 方向鍵 ↑↑↓↓←→←→，接著 B、A 鍵（手把為十字鍵，接著 B、A 鍵；每一鍵要在前一鍵之後約 1 秒內按下）：戰爭迷霧全部打開、體力回滿。再輸入一次，迷霧還原。只在遊戲場景有效，不會寫進存檔。

## 開發歷程

### 2026-11-09　FC 版（標籤 `fc-v1`）

- 原創 FC／NES 風格的日式黑暗動作 RPG：Canvas 2D 與 Web Audio，圖像、音樂、音效都由程式產生。

### 2026-11-09　PS2 世代重製（`ps2-remake` 分支，合併回 `main`）

- 改用 Three.js（WebGL2）重製：2D 模式是斜角視角的大地圖、村莊、古道；3D 模式是迷宮與 Boss 的第三人稱劍戟動作。配樂改用取樣音源。第一章可以完整試玩。
- 第一章試玩後的調整：
  - 鍵盤和滑鼠可以混用；選單與遊戲中的互動都能用滑鼠操作。
  - 3D 用滑鼠控制視角；2D 改成 Diablo 式的點擊移動與攻擊。
  - 大地圖也有迷你地圖與戰爭迷霧。
  - 攻擊加上緩動與更早的取消時機；戰鬥加入刀光、受擊閃光、擊退、打擊停頓與反擊慢動作。
  - 「褪色木版畫」畫面（墨線、和紙、套色錯位），場景加上風化物件與用 Blender 建模的原創道具。
  - 測試用密技。
- 解除 PS2 世代的限制：畫面填滿視窗並支援寬螢幕、動態解析度、SMAA、高更新率螢幕的插值繪製。

### 2026-11-10　第一章試玩修正（`playtest-fixes` 分支，合併回 `main`）

- 新增難度（簡單／一般／困難）：開新遊戲時選，之後可在設定中更改，隨存檔保存。
- 新增跑步（C 鍵切換）與疲勞：跑太久會力竭，停下來可以休息恢復；走路也會累，但累得很慢。
- 重新調整戰爭迷霧：未探索的地面在畫面上蓋著流動的墨霧，迷你地圖也蓋上墨色；主角揭開的範圍改為 12 m。
- 修正按倒退鍵時人物變成背著走：鏡頭不再跟著轉，人物先轉身再走。
- 修正走路時人物抽動：走路循環改用平滑曲線，補上換腳時漏設的左手角度，動作交叉淡入被打斷時不再跳動，起步與停步的淡入延長為 0.2 秒。
- 鏡頭：3D 鏡頭在牆邊平順地拉近；2D 按住滑鼠移動時路線不再忽左忽右。
- 原創道具的 Blender 檔 `scripts/blender/props.blend` 加入版本控制（`blender-data` 分支，合併回 `main`）。
- 修正人物持續抽動：面向背對 +Z 的那半圈時，畫面上的朝向每幀在兩個方向間來回翻轉，主角、敵人、村民都受影響。原因是插值繪製畫完後寫回姿勢時改掉了歐拉角，現在連歐拉角一起還原（`facing-fix` 分支，合併回 `main`）。

### 2026-11-10　iPhone 原生版與鏡頭調整（`1.0` build `10`）

- 新增獨立的 [iPhone 原生版](ios/README.md)：Swift 6、RealityKit 非 AR、SwiftUI 與 UIKit 多點觸控，最低 iOS 26、iPhone 橫向；接入原版模型、關節動畫、第一章場景、戰鬥與原生 Metal 後製，存檔與網頁版獨立。
- 拉近鏡頭以改善人物過小的問題：平原、村莊與古道的正交 scale 從 `10.5` 改為 `7.2`；洞窟與 Boss 戰的跟隨距離上限從 `6.2` 改為 `4.2`、基礎高度從 `2.4` 降為 `1.8`。同位置、同姿勢的幾何投影高度約增加 46%／51%，實際比例隨避障與俯仰改變。
- 第三人稱進場與跟隨共用鏡頭位置計算，保留 `61°` 視野、注視點、避障、平滑追蹤與手動旋轉。
- `1.0` build `10` 已安裝至 iPhone 15 Pro。7 組核心測試（含三種難度整章案例）、iOS 建置、實機 UI 與洞窟操作測試通過；短程巡迴完成一次第一章，未記錄資產載入錯誤。
- 依使用者指示停止追加測試並交付；Boss 地面預警專項、逐幀平順度、同位置實機前後像素量測與真人手感仍待驗收。完整結果與證據位置見 [iOS 驗證紀錄](ios/VALIDATION.md#2026-11-10-鏡頭調整build-10)。
